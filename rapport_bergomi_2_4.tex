\section{Bergomi, Chapitre 2.4 -- Des volatilites locales aux volatilites implicites}

\section{Objet du rapport}

Ce rapport est volontairement cale sur \textbf{le meme contenu que les slides actuels}.

Autrement dit, il developpe en detail les points suivants, et \textbf{seulement} ceux-la :

\begin{enumerate}
\item le probleme "local vol \(\to\) implied vol" ;
\item l'identite exacte : variance implicite comme moyenne ponderee de variance locale ;
\item l'approximation weak local vol ;
\item le developpement de la local vol pres du forward ;
\item les formules de skew et de courbure implicites ;
\item le cas d'une structure par terme du skew en loi de puissance ;
\item le resultat exact a courte maturite ;
\item la conclusion conceptuelle : lien avec Dupire, lien avec la stoch vol, et limites.
\end{enumerate}

Donc :

\begin{itemize}
\item je garde un niveau \textbf{tres detaille} ;
\item mais je ne developpe pas ici des blocs supplementaires qui ne figurent plus dans les slides actuels, comme une section autonome sur \(R_T\) ou la dynamique ATMF.
\end{itemize}

\bigskip\hrule\bigskip

\section{1. La question posee par Bergomi}

\subsection{1.1. Le point de depart}

Dans un modele de volatilite locale, on suppose que sous la mesure risque-neutre :

\[
dS_t=(r-q)S_t\,dt+\sigma_{\mathrm{loc}}(t,S_t)S_t\,dW_t.
\]

Ici :

\begin{itemize}
\item \(S_t\) est le prix du sous-jacent ;
\item \(r\) est le taux sans risque ;
\item \(q\) est le taux de dividende / carry ;
\item \(\sigma_{\mathrm{loc}}(t,S)\) est une fonction \textbf{deterministe} du temps et du spot.
\end{itemize}

Le probleme usuel de Dupire est :

\[
\widehat{\sigma}(K,T)\quad \longrightarrow \quad \sigma_{\mathrm{loc}}(t,S).
\]

Le probleme de Bergomi dans la section 2.4 est le probleme inverse :

\[
\sigma_{\mathrm{loc}}(t,S)\quad \longrightarrow \quad \widehat{\sigma}(K,T).
\]

\subsection{1.2. Pourquoi cette question est importante ?}

Parce que calibrer un modele local vol revient a dire :

> "je choisis une fonction \(\sigma_{\mathrm{loc}}(t,S)\) qui reproduit aujourd'hui la surface vanille."

Mais alors une question naturelle est :

> "qu'est-ce que cette fonction implique pour les volatilites implicites, et quelle structure mathematique se cache derriere cette implication ?"

Le chapitre 2.4 donne une reponse en deux temps :

\begin{enumerate}
\item une \textbf{identite exacte} ;
\item une \textbf{approximation analytique exploitable}.
\end{enumerate}

\bigskip\hrule\bigskip

\section{2. Rappels minimaux de cours pour comprendre la derivee}

Comme tu m'as dit que certaines notions n'etaient pas claires, je rappelle ici les objets indispensables.

\subsection{2.1. Prix d'une option}

Si \(P(t,S)\) est le prix d'une option europeenne, alors dans un modele de diffusion de volatilite \(\sigma(t,S)\), on a formellement :

\[
\partial_t P+(r-q)S\partial_S P+\frac12 \sigma^2(t,S)S^2\partial_{SS}P-rP=0.
\]

Cette equation vient du cours par Itô, replication et absence d'arbitrage.

\subsection{2.2. Delta, gamma, theta}

On note :

\[
\Delta=\partial_S P,\qquad
\Gamma=\partial_{SS}P,\qquad
\Theta=\partial_t P.
\]

Interpretation :

\begin{itemize}
\item \(\Delta\) = sensibilite lineaire au spot ;
\item \(\Gamma\) = courbure, donc sensibilite du delta ;
\item \(\Theta\) = effet du temps.
\end{itemize}

\subsection{2.3. Qu'est-ce qu'un P\&L de couverture delta ?}

Le \textbf{P\&L} ("profit and loss") est le gain ou la perte realise sur un petit intervalle de temps.

Si l'on detient une option et que l'on prend en face \(-\Delta\) actions, le terme lineaire en \(dS_t\) disparait.

Par Itô :

\[
dP=\partial_t P\,dt+\partial_S P\,dS+\frac12 \partial_{SS}P\,d\langle S\rangle.
\]

Si l'on retranche \(\Delta\,dS\), il reste un terme de type :

\[
\partial_t P\,dt+\frac12 \Gamma\,d\langle S\rangle.
\]

Autrement dit, dans une couverture delta, le residu est de type :

\begin{itemize}
\item theta ;
\item plus gamma fois variation quadratique.
\end{itemize}

\textbf{C'est exactement pourquoi le gamma apparait dans Bergomi.}

\bigskip\hrule\bigskip

\section{3. Section 2.4.1 -- Identite exacte : moyenne ponderee de variance locale}

\subsection{3.1. Idee generale}

Bergomi compare deux modeles :

\begin{itemize}
\item \textbf{modele I} : modele de reference, avec prix d'option \(P_1(t,S)\) et volatilite instantanee \(\sigma_1(t,S)\) ;
\item \textbf{modele II} : modele "reel", dans lequel le sous-jacent suit
\end{itemize}
\[
  dS_t=(r-q)S_t\,dt+\sigma_{2,t}S_t\,dW_t.
\]

Le but est de comprendre :

> quel est le prix de l'erreur faite lorsque l'on couvre l'option avec le modele I alors que le sous-jacent evolue en realite selon le modele II ?

\subsection{3.2. Quantite actualisee}

On introduit :

\[
Q_t=e^{-rt}P_1(t,S_t).
\]

Cette quantite est naturelle car les quantites actualisees sont les bonnes quantites en pricing sous mesure risque-neutre.

\subsection{3.3. Application de la formule d'Itô}

Sous le modele II :

\[
dQ_t
=
e^{-rt}
\left[
\left(-rP_1+\partial_t P_1\right)dt
+
\partial_S P_1\,dS_t
+
\frac12 \partial_{SS}P_1\,d\langle S\rangle_t
\right].
\]

Or

\[
d\langle S\rangle_t=\sigma_{2,t}^2S_t^2\,dt.
\]

Donc :

\[
dQ_t
=
e^{-rt}
\left[
\left(-rP_1+\partial_t P_1\right)dt
+
\partial_S P_1\,dS_t
+
\frac12 \sigma_{2,t}^2S_t^2\partial_{SS}P_1\,dt
\right].
\]

En prenant l'esperance conditionnelle, le terme brownien disparait :

\[
\mathbb E_2[dQ_t\mid\mathcal F_t]
=
e^{-rt}
\left[
-rP_1+\partial_t P_1+(r-q)S_t\partial_S P_1+\frac12 \sigma_{2,t}^2S_t^2\partial_{SS}P_1
\right]dt.
\]

\subsection{3.4. Utilisation de l'EDP du modele I}

Dans le modele I, \(P_1\) satisfait :

\[
\partial_t P_1+(r-q)S\partial_S P_1+\frac12 \sigma_1^2(t,S)S^2\partial_{SS}P_1-rP_1=0.
\]

Donc :

\[
-rP_1+\partial_t P_1+(r-q)S_t\partial_S P_1
=
-\frac12 \sigma_1^2(t,S_t)S_t^2\partial_{SS}P_1.
\]

En remplaçant :

\[
\mathbb E_2[dQ_t\mid\mathcal F_t]
=
e^{-rt}\frac12 S_t^2\partial_{SS}P_1(t,S_t)\big(\sigma_{2,t}^2-\sigma_1^2(t,S_t)\big)\,dt.
\]

\subsection{3.5. Interpretation en P\&L}

Cette formule dit exactement :

> le drift residuel de la couverture delta est proportionnel au gamma, et a l'ecart entre la variance instantanee du monde reel et celle du modele de couverture.

Donc :

\begin{itemize}
\item si \(\sigma_{2,t}^2=\sigma_1^2(t,S_t)\), il n'y a pas d'erreur residuelle ;
\item sinon, un ecart de P\&L apparait ;
\item plus l'option est convexe, plus cet ecart est important.
\end{itemize}

\subsection{3.6. Integration jusqu'a maturite}

En integrant entre \(0\) et \(T\) :

\[
\mathbb E_2[Q_T]
=
Q_0+
\mathbb E_2\left[
\int_0^T e^{-rt}\frac12 S_t^2\partial_{SS}P_1(t,S_t)\big(\sigma_{2,t}^2-\sigma_1^2(t,S_t)\big)\,dt
\right].
\]

Comme

\[
Q_T=e^{-rT}f(S_T),
\]

on a

\[
\mathbb E_2[Q_T]=P_2(0,S_0,\cdot),
\qquad
Q_0=P_1(0,S_0).
\]

Donc :

\[
\boxed{
P_2(0,S_0,\cdot)
=
P_1(0,S_0)
+
\mathbb E_2\left[
\int_0^T e^{-rt}\frac12 S_t^2\partial_{SS}P_1(t,S_t)\big(\sigma_{2,t}^2-\sigma_1^2(t,S_t)\big)\,dt
\right].
}
\]

\subsection{3.7. Choix Black-Scholes et identite exacte}

On choisit maintenant comme modele I le modele Black-Scholes de volatilite constante egale a la volatilite implicite de l'option :

\[
\sigma_1(t,S)\equiv \widehat{\sigma}_{K,T}.
\]

Par definition meme de \(\widehat{\sigma}_{K,T}\), le prix Black-Scholes et le prix de l'option coincident a \(t=0\).

Donc le membre de gauche moins le premier terme du membre de droite vaut zero.

Il reste :

\[
0=
\mathbb E_2\left[
\int_0^T e^{-rt}\frac12 S_t^2\Gamma_t^{BS}(\widehat{\sigma}_{K,T})\big(\sigma_{2,t}^2-\widehat{\sigma}_{K,T}^2\big)\,dt
\right].
\]

En isolant \(\widehat{\sigma}_{K,T}^2\), on obtient :

\[
\widehat{\sigma}_{K,T}^{\,2}
=
\frac{
\mathbb E_2\left[
\int_0^T e^{-rt}S_t^2\Gamma_t^{BS}(\widehat{\sigma}_{K,T})\,\sigma_{2,t}^2\,dt
\right]
}{
\mathbb E_2\left[
\int_0^T e^{-rt}S_t^2\Gamma_t^{BS}(\widehat{\sigma}_{K,T})\,dt
\right]
}.
\]

Si le modele II est justement le modele local vol, c'est-a-dire \(\sigma_{2,t}=\sigma_{\mathrm{loc}}(t,S_t)\), alors :

\[
\boxed{
\widehat{\sigma}_{K,T}^{\,2}
=
\frac{
\mathbb E^{\mathrm{loc}}\!\left[
\int_0^T e^{-rt}S_t^2\Gamma_t^{BS}(\widehat{\sigma}_{K,T})
\sigma_{\mathrm{loc}}^2(t,S_t)\,dt
\right]
}{
\mathbb E^{\mathrm{loc}}\!\left[
\int_0^T e^{-rt}S_t^2\Gamma_t^{BS}(\widehat{\sigma}_{K,T})\,dt
\right]
}.
}
\]

\subsection{3.8. Interpretation precise}

Cette formule signifie :

\begin{itemize}
\item l'objet exact est la \textbf{variance implicite} ;
\item elle est une \textbf{moyenne ponderee de variance locale} ;
\item les poids sont des \textbf{dollar gammas actualises}.
\end{itemize}

Warning essentiel :

\begin{itemize}
\item \textbf{exactement} : moyenne de \(\sigma_{\mathrm{loc}}^2\) ;
\item \textbf{pas} moyenne directe de \(\sigma_{\mathrm{loc}}\).
\end{itemize}

\section{4. Section 2.4.2 et 2.4.3 -- Approximation weak local vol}

\subsection{4.1. Pourquoi une approximation est necessaire ?}

L'identite precedente est exacte, mais implicite :

\begin{itemize}
\item \(\widehat{\sigma}_{K,T}\) apparait des deux cotes ;
\item les poids dependent eux-memes de \(\widehat{\sigma}_{K,T}\).
\end{itemize}

Donc on cherche une approximation analytique.

\subsection{4.2. Hypothese weak local vol}

On ecrit la variance locale comme :

\[
u(t,S)=\sigma_{\mathrm{loc}}^2(t,S)=u_0(t)+\delta u(t,S),
\]

ou bien, dans le cas plus simple :

\[
\sigma_{\mathrm{loc}}(t,S)=\sigma_0+\delta\sigma(t,S),
\]

avec perturbation petite.

L'idee est :

\begin{itemize}
\item prendre un modele de reference simple ;
\item figer la loi au premier ordre ;
\item garder seulement la contribution explicite de la perturbation.
\end{itemize}

\subsection{4.3. Ce que veut dire "faiblement locale" en langage simple}

Le mot \emph{weakly local} peut sembler obscur si on le lit trop vite.

Ce que Bergomi veut dire est simplement :

> la dependance de la volatilite locale en fonction du spot est assez faible pour que l'on puisse faire un developpement perturbatif autour d'un modele plus simple.

Autrement dit, on ne dit pas :

\begin{itemize}
\item "la local vol est constante" ;
\item ni "la local vol ne depend presque pas du temps" ;
\end{itemize}

mais plutot :

\begin{itemize}
\item "la partie difficile, c'est sa dependance en \(S\)" ;
\item "on la traite comme une petite perturbation".
\end{itemize}

Donc, conceptuellement :

\[
\sigma_{\mathrm{loc}}(t,S)
=
\underbrace{\sigma_0}_{\text{modele simple}}
+
\underbrace{\delta\sigma(t,S)}_{\text{correction petite}}.
\]

Le modele simple, ici, est Black-Scholes de volatilite constante \(\sigma_0\).

\subsection{4.4. Quelle est l'idee mathematique exacte ?}

L'idee mathematique est une idee tres classique du cours :

\begin{enumerate}
\item on part d'une formule exacte difficile ;
\item on ecrit l'objet complique comme "objet simple + petite perturbation" ;
\item on developpe a l'ordre 1 ;
\item on jette les termes quadratiques et d'ordre superieur.
\end{enumerate}

Ici, l'objet complique est la fonction locale \(\sigma_{\mathrm{loc}}(t,S)\), ou plus proprement sa variance locale :

\[
u(t,S)=\sigma_{\mathrm{loc}}^2(t,S)=u_0(t)+\delta u(t,S).
\]

Le modele simple correspondant est un modele lognormal de reference, dans lequel les calculs de densite et de gamma se font explicitement.

Le gain est enorme :

\begin{itemize}
\item on perd de l'exactitude ;
\item mais on gagne une formule interpretable.
\end{itemize}

\subsection{4.5. Le vrai obstacle : qu'est-ce qui depend de la local vol ?}

Il faut bien voir que dans la formule exacte, la local vol intervient a deux endroits :

\begin{enumerate}
\item \textbf{explicitement} dans le terme \(\sigma_{\mathrm{loc}}^2(t,S_t)\) du numerateur ;
\item \textbf{implicitement} parce que la loi de \(S_t\) elle-meme depend du modele local vol.
\end{enumerate}

Et c'est justement cela qui rend la formule exacte difficile :

\begin{itemize}
\item le poids n'est pas fixe ;
\item la densite des trajectoires n'est pas fixe ;
\item tout depend du modele local vol.
\end{itemize}

L'approximation weak local vol consiste donc a dire :

> au premier ordre, on peut calculer les poids et la densite dans le modele simple de reference, et ne garder la perturbation que dans le facteur explicite.

\subsection{4.6. Pourquoi dit-on qu'on "fige la densite" ?}

Supposons qu'on sache calculer facilement les esperances dans un modele simple de reference.

Alors, au lieu de calculer exactement

\[
\mathbb E_{\mathrm{loc}}[\cdots],
\]

on remplace, a l'ordre 1, la loi compliquee par la loi du modele de reference.

Ce n'est pas magique : c'est un developpement de perturbation.

L'idee est :

\[
\mathbb E_{\mathrm{loc}}[\cdots]
\approx
\mathbb E_{0}[\cdots]
\]

pour la partie qui sert a calculer les poids, tant qu'on reste au premier ordre.

\subsection{4.7. Pourquoi la correction de densite disparait a l'ordre 1 ?}

C'est le point le plus subtil de cette section, et souvent celui qu'on ne comprend pas a la premiere lecture.

La logique est la suivante.

La formule exacte a la structure :

\[
\widehat{\sigma}_{K,T}^{\,2}
=
\frac{\mathbb E[(u_0+\delta u)\,\bullet]}{\mathbb E[\bullet]},
\]

ou \(\bullet\) designe schematiquement le poids gamma et l'integration en temps.

Si tout dependait lineairement de \(\delta u\), on pourrait penser qu'il faut developper :

\begin{itemize}
\item la perturbation explicite du numerateur ;
\item la perturbation de la loi dans le numerateur ;
\item la perturbation de la loi dans le denominateur.
\end{itemize}

Mais, au premier ordre, les termes venant de la perturbation de la loi se compensent exactement entre numerateur et denominateur.

Le mecanisme algebrique est celui-ci :

si l'on ecrit

\[
\frac{A_0+\delta A}{B_0+\delta B}
=
\frac{A_0}{B_0}
+
\frac{\delta A\,B_0-A_0\,\delta B}{B_0^2}
+
O(\delta^2),
\]

et si, a l'ordre zero, on a

\[
A_0=u_0 B_0,
\]

alors

\[
\frac{\delta A\,B_0-A_0\,\delta B}{B_0^2}
=
\frac{\delta A-u_0\delta B}{B_0}.
\]

Or la partie de \(\delta A\) qui vient uniquement de la modification de la loi vaut exactement \(u_0\delta B\).

Donc elle s'annule.

Il reste seulement la contribution explicite de \(\delta u\).

\subsection{4.8. Qu'est-ce qu'il faut retenir de ce point technique ?}

Si tu veux une phrase simple a dire a l'oral :

> au premier ordre, on peut calculer les poids et la densite dans le modele de reference ; la perturbation de la loi ne contribue pas independamment, elle se compense dans le quotient.

C'est cela qui rend possible la formule analytique approchée.

\subsection{4.9. Formule approchee autour d'une vol constante}

Autour d'une vol constante \(\sigma_0\), Bergomi obtient :

\[
\widehat{\sigma}_{K,T}
\approx
\frac{1}{T}
\int_0^T dt
\int_{\mathbb R}\phi(y)\,
\sigma_{\mathrm{loc}}\!\left(
t,\,
F_t\exp\!\Big(
\frac{t}{T}x_K+\sigma_0\sqrt{\frac{(T-t)t}{T}}\,y
\Big)
\right)dy,
\]

avec

\[
x_K=\ln\!\left(\frac{K}{F_T}\right),
\qquad
\phi(y)=\frac{e^{-y^2/2}}{\sqrt{2\pi}}.
\]

\subsection{4.10. D'ou vient la variable \(y\) ?}

La variable \(y\) est une variable gaussienne centree reduite.

Elle apparait quand on remplace la loi exacte compliquee de l'actif par la loi lognormale du modele de reference.

Dans ce modele de reference :

\begin{itemize}
\item le log-spot est gaussien ;
\item le conditionnement implicite entre la date \(0\) et la date \(T\) fait apparaitre une interpolation lineaire en log-moneyness ;
\item la partie aleatoire autour de cette interpolation est de type gaussien.
\end{itemize}

C'est pour cela qu'on obtient une formule avec

\[
\int_{\mathbb R}\phi(y)\,\cdots\,dy.
\]

Donc \(y\) ne doit pas etre vu comme une nouvelle variable economique.

Il faut plutot le voir comme :

> la variable auxiliaire qui parametre les deviations gaussiennes autour du chemin central dans l'approximation lognormale.

\subsection{4.11. Que represente exactement \(x_K\) ?}

On pose

\[
x_K=\ln\!\left(\frac{K}{F_T}\right).
\]

C'est le \textbf{log-moneyness forward}.

Interpretation :

\begin{itemize}
\item si \(x_K=0\), on est au forward, donc a l'ATMF ;
\item si \(x_K<0\), le strike est en dessous du forward ;
\item si \(x_K>0\), le strike est au-dessus du forward.
\end{itemize}

Cette variable est naturelle car le modele local vol est developpe autour du forward, pas autour du spot brut.

\subsection{4.12. Pourquoi la formule a cette tete ?}

Regardons

\[
S(t,y)=F_t\exp\!\Big(
\frac{t}{T}x_K+\sigma_0\sqrt{\frac{(T-t)t}{T}}\,y
\Big).
\]

Cette formule se lit tres bien morceau par morceau :

\begin{enumerate}
\item \(F_t\) = niveau central naturel a la date \(t\) ;
\item \(\frac{t}{T}x_K\) = interpolation lineaire en log-espace entre la situation initiale et le strike final ;
\item \(\sigma_0\sqrt{\frac{(T-t)t}{T}}\,y\) = dispersion gaussienne autour de ce chemin central.
\end{enumerate}

Le facteur

\[
\sqrt{\frac{(T-t)t}{T}}
\]

est tres important :

\begin{itemize}
\item il vaut \(0\) a \(t=0\) ;
\item il vaut \(0\) a \(t=T\) ;
\item il est maximal au milieu.
\end{itemize}

Donc les trajectoires alternatives sont "clouees" au point initial et au point final, et se dispersent surtout au milieu.

\subsection{4.13. Interpretation geometrique complete}

Cette formule dit :

> l'implicite est approximativement une moyenne gaussienne de la local vol le long de chemins intermediaires reliant \(S_0\) au strike \(K\).

Le terme

\[
S(t,y)=F_t\exp\!\Big(
\frac{t}{T}x_K+\sigma_0\sqrt{\frac{(T-t)t}{T}}\,y
\Big)
\]

decrit le spot intermediaire visite a la date \(t\).

Si l'on garde seulement \(y=0\), on retient le chemin central, souvent interprete comme le "chemin le plus probable".

Autrement dit :

\begin{itemize}
\item l'implicite est une moyenne en temps ;
\item et, pour chaque temps, une moyenne sur un faisceau de chemins gaussiens ;
\item le coeur de l'approximation est donc une \textbf{moyenne gaussienne de local vol}.
\end{itemize}

\subsection{4.14. Pourquoi la moyenne est-elle gaussienne ?}

Parce que le modele de reference est Black-Scholes.

Dans Black-Scholes :

\begin{itemize}
\item les incréments du log-prix sont gaussiens ;
\item la densite de transition est donc lognormale pour le prix ;
\item apres changement de variable, l'integration se ramene a une integration contre la densite normale standard \(\phi(y)\).
\end{itemize}

Donc la gaussienne n'est pas arbitraire :

> elle est la signature du fait qu'on calcule l'approximation autour d'un modele lognormal de reference.

\subsection{4.15. Ce qu'il faut absolument comprendre si on ne retient qu'une chose}

Si tu ne retiens qu'une seule idee sur l'approximation weak local vol, retiens celle-ci :

> on remplace un probleme exact mais implicite et difficile par une moyenne gaussienne explicite de la local vol calculee dans un modele de reference Black-Scholes.

Et si tu veux la dire encore plus simplement :

> l'implicite est approximativement ce que l'on obtient en "moyennant" la local vol le long de chemins lognormaux reliant le spot initial au strike.

\subsection{4.16. Warning}

Cette formule est tres utile pour comprendre les derivations du skew.

Mais Bergomi insiste :

\begin{itemize}
\item elle est d'ordre 1 ;
\item elle est bonne pour l'intuition ;
\item elle n'est pas suffisante pour une precision de trading sur des smiles equity realistes.
\end{itemize}

\bigskip\hrule\bigskip

\section{5. Section 2.4.5 -- Smile pres du forward}

\subsection{5.1. Parametrisation locale}

On developpe la local vol autour du forward \(F_t\) :

\[
\sigma_{\mathrm{loc}}(t,S)=\bar{\sigma}(t)+\alpha(t)x+\frac{\beta(t)}{2}x^2,
\qquad
x=\ln\!\left(\frac{S}{F_t}\right).
\]

Interpretation :

\begin{itemize}
\item \(\bar{\sigma}(t)\) = niveau local ;
\item \(\alpha(t)\) = skew local instantane ;
\item \(\beta(t)\) = courbure locale instantanee.
\end{itemize}

\subsection{5.2. Variable intermediaire}

Dans la formule weak local vol, on pose

\[
X(t,y)=\frac{t}{T}x_K+\sigma_0\sqrt{\frac{(T-t)t}{T}}\,y.
\]

En remplaçant \(x\) par \(X(t,y)\), on obtient :

\[
\sigma_{\mathrm{loc}}(t,S(t,y))
=
\bar{\sigma}(t)+\alpha(t)X(t,y)+\frac{\beta(t)}{2}X(t,y)^2.
\]

\subsection{5.3. Calcul des moyennes gaussiennes}

Comme \(y\) est gaussien centre reduit :

\[
\int_{\mathbb R}\phi(y)\,y\,dy=0,
\qquad
\int_{\mathbb R}\phi(y)\,y^2\,dy=1.
\]

Donc, a l'ordre 1 en \(\alpha,\beta\), on trouve :

\[
\widehat{\sigma}_{K,T}
\approx
\frac{1}{T}\int_0^T \bar{\sigma}(t)\,dt
\;+\;
\left(
\frac{1}{T}\int_0^T \frac{t}{T}\alpha(t)\,dt
\right)x_K
\;+\;
\frac12
\left(
\frac{1}{T}\int_0^T\Big(\frac{t}{T}\Big)^2\beta(t)\,dt
\right)x_K^2.
\]

\subsection{5.4. Skew implicite pres du forward}

En derivant par rapport a \(\ln K\) puis en evaluant en \(K=F_T\) (donc \(x_K=0\)), on obtient :

\[
\boxed{
\left.\frac{\partial \widehat{\sigma}_{K,T}}{\partial\ln K}\right|_{K=F_T}
=
\frac{1}{T}\int_0^T \frac{t}{T}\alpha(t)\,dt.
}
\]

Interpretation :

> le skew implicite est une moyenne ponderee du skew local \(\alpha(t)\).

Le poids \(t/T\) donne plus d'importance aux temps proches de la maturite.

\subsection{5.5. Courbure implicite pres du forward}

De meme :

\[
\boxed{
\left.\frac{\partial^2 \widehat{\sigma}_{K,T}}{\partial(\ln K)^2}\right|_{K=F_T}
=
\frac{1}{T}\int_0^T \Big(\frac{t}{T}\Big)^2\beta(t)\,dt.
}
\]

\subsection{5.6. Cas constant}

Si \(\alpha(t)\equiv\alpha\), alors :

\[
\left.\frac{\partial \widehat{\sigma}_{K,T}}{\partial\ln K}\right|_{K=F_T}
=
\frac{\alpha}{2}.
\]

Donc :

> quand le skew local est constant dans le temps, le skew implicite ATMF vaut la moitie du skew local.

\bigskip\hrule\bigskip

\section{6. Structure par terme du skew : loi de puissance}

On suppose :

\[
\alpha(t)=
\begin{cases}
\alpha_0, & t\le \tau_0,\\[0.3em]
\alpha_0\left(\dfrac{\tau_0}{t}\right)^\gamma, & t>\tau_0.
\end{cases}
\]

Alors, pour \(T\) grand devant \(\tau_0\),

\[
\left.\frac{\partial \widehat{\sigma}_{K,T}}{\partial\ln K}\right|_{K=F_T}
\sim
\frac{1}{2-\gamma}\,
\alpha_0\left(\frac{\tau_0}{T}\right)^\gamma.
\]

\subsection{Interpretation}

Ce resultat signifie :

\begin{itemize}
\item le skew implicite ATMF decroit avec le \textbf{meme exposant} \(\gamma\) que le skew local ;
\item la structure par terme du smile implicite herite directement de la structure par terme de \(\alpha(t)\).
\end{itemize}

Autrement dit :

> \(\alpha(t)\) controle non seulement le niveau du skew, mais aussi sa decroissance avec la maturite.

\bigskip\hrule\bigskip

\section{7. Section 2.4.6 -- Resultat exact a courte maturite}

\subsection{7.1. Point de depart}

Quand \(T\to 0\), Bergomi part de la formule de Dupire dans les coordonnees \((T,y)\), avec

\[
y=\ln(K/S_0).
\]

En gardant les termes dominants en petite maturite, on obtient finalement une relation exacte entre local vol et implicite.

\subsection{7.2. Resultat exact}

\[
\boxed{
\frac{1}{\widehat{\sigma}(0,K)}
=
\frac{1}{\ln(K/S_0)}
\int_{S_0}^{K}\frac{dS}{S\,\sigma_{\mathrm{loc}}(0,S)}.
}
\]

\subsection{7.3. Interpretation}

Ce resultat dit que, a maturite tres courte :

\begin{itemize}
\item on n'obtient pas une moyenne arithmetique de \(\sigma_{\mathrm{loc}}\) ;
\item ni une moyenne quadratique ;
\item mais une \textbf{moyenne harmonique} de \(1/\sigma_{\mathrm{loc}}\).
\end{itemize}

Autrement dit :

> a tres courte maturite, il n'y a presque plus de moyenne temporelle ; ce qui domine est une moyenne spatiale entre \(S_0\) et \(K\).

\subsection{7.4. Pourquoi est-ce naturel ?}

Si \(\sigma_{\mathrm{loc}}(0,S)\) devient tres faible sur une region qu'il faut franchir pour aller de \(S_0\) a \(K\), alors le sous-jacent a beaucoup de mal a traverser cette region sur une maturite tres courte.

Il est donc naturel que l'implicite reflète cette difficulte de passage.

C'est exactement ce que capture la moyenne harmonique.

\bigskip\hrule\bigskip

\section{8. A retenir : Dupire, stoch vol, limites}

\subsection{8.1. Lien avec Dupire}

Dupire fait le chemin :

\[
\widehat{\sigma}(K,T)\quad \longrightarrow \quad \sigma_{\mathrm{loc}}(t,S).
\]

Le chapitre 2.4 etudie l'autre sens :

\[
\sigma_{\mathrm{loc}}(t,S)\quad \longrightarrow \quad \widehat{\sigma}(K,T).
\]

\subsection{8.2. Lien avec les modeles de volatilite stochastique}

Le modele local vol est tres utile pour comprendre analytiquement le smile.

Mais les modeles de volatilite stochastique sont souvent preferes en pratique pour la dynamique, car ils introduisent des facteurs aleatoires supplementaires pour la variance future.

\subsection{8.3. Limite majeure de l'approximation weak local vol}

L'approximation d'ordre 1 :

\begin{itemize}
\item explique bien le skew et la courbure ;
\item donne une bonne intuition ;
\item mais n'est pas assez precise pour les \textbf{niveaux absolus} sur des smiles equity realistes.
\end{itemize}

\subsection{8.4. Message central de la section}

Le message essentiel de Bergomi, dans le perimetre des slides actuels, est :

> l'implicite n'est pas un objet arbitraire ; elle est fortement contrainte par la structure spatio-temporelle de la volatilite locale.

Et plus precisement :

\begin{itemize}
\item l'identite exacte porte sur une moyenne ponderee de \textbf{variance locale} ;
\item l'ordre 1 weak local vol donne une moyenne exploitable de \textbf{volatilite locale} ;
\item le skew implicite pres du forward est gouverne par \(\alpha(t)\) ;
\item la structure par terme du skew implicite herite de celle de \(\alpha(t)\) ;
\item a tres courte maturite, on obtient une moyenne harmonique exacte.
\end{itemize}

\bigskip\hrule\bigskip

\section{9. Resume ultra-court pour l'examen}

Si tu dois retenir seulement six phrases, retiens celles-ci :

\begin{enumerate}
\item Bergomi inverse la logique de Dupire : il part de \(\sigma_{\mathrm{loc}}(t,S)\) et cherche \(\widehat{\sigma}(K,T)\).
\item La formule exacte dit que \(\widehat{\sigma}_{K,T}^2\) est une moyenne ponderee de \(\sigma_{\mathrm{loc}}^2\), avec des poids de type dollar gamma.
\item L'approximation weak local vol donne une formule analytique d'ordre 1 pour \(\widehat{\sigma}_{K,T}\).
\item Pres du forward, le skew implicite est une moyenne ponderee de \(\alpha(t)\), avec poids \(t/T\).
\item Si \(\alpha(t)\) suit une loi de puissance, le skew implicite decroit avec le meme exposant.
\item Quand \(T\to 0\), l'inverse de l'implicite est une moyenne harmonique de l'inverse de la local vol.
\end{enumerate}
